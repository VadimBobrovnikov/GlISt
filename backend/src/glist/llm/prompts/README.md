# Правила версионирования промптов (T024)

Все промпты LLM хранятся в этой папке. Каждый промпт должен иметь версию и
очевидное имя, отражающее его назначение.

## Именование файлов

`<имя_задачи>_v<версия>.txt` — например:
- `analysis_run_v1.txt`
- `clarification_request_v2.txt`

## Версионирование

1. Промпт версии `v1` — исходная версия, утверждённая при запуске задачи.
2. Любое изменение текста промпта — увеличение минорной версии (`v2`, `v3`…).
3. Критические изменения (изменение формата ответа, новой логики валидации) —
   увеличение-major версии (`v2.0`, `v3.0`).
4. Старые версии не удаляются — они могут использоваться для отката.

## Требования к содержимому

- Каждый промпт должен начинаться с заголовка: `Версия: X.Y — описание`.
- Промпт должен быть自我-документированным: ясно указано, что ожидается от LLM.
- Чувствительные данные (секреты, ключи) в промптах не хранятся (Принцип IX).

## Использование в коде

Промпты загружаются через `get_prompt(name, version)` (появится в T025+).
Загрузка кэшируется на время жизни процесса.
