# Дизайн-система GlISt (Визуальный контракт)

## Общие принципы
- Стиль: Современный data-dashboard, Material Design 3.
- Интерфейс: русскоязычный.
- Шрифт: Inter или Roboto.

## Цветовая палитра
- Фон приложения: #F8FAFC (светло-серый)
- Основной акцент (кнопки, ссылки): #2563EB (синий)
- Текст: #0F172A (темно-серый)

## Карта (3 слоя)
- Сохранившиеся зоны (зеленый): #22C55E с прозрачностью 40%
- Потерянные зоны (красный): #EF4444 с прозрачностью 40%
- Новые зоны (желтый): #FACC15 с прозрачностью 40%

## Статусы (бейджи)
- В процессе: Синий фон, синий текст
- Завершено: Светло-зеленый фон (#DCFCE7), зеленый текст (#166534)
- Не прошел проверку: Светло-оранжевый фон (#FEF3C7), оранжевый текст (#92400E)
- Ошибка: Светло-красный фон (#FEE2E2), красный текст (#991B1B)

## Ключевые компоненты
1. **Экран ввода:** Большое поле ввода по центру, чипы быстрых шаблонов снизу.
2. **Экран прогресса:** 4 карточки агентов (Researcher, Analyst, Visualizer, Validator). У каждой статус и краткий лог.
3. **Экран результата:** Карта на 70% экрана. Боковая панель (30%) с общей динамикой (например -12%), разбивкой по площадям и кнопками скачивания PDF/GeoJSON.
4. **Экран истории:** Список карточек с миниатюрами карт и цветовыми бейджами статусов.
